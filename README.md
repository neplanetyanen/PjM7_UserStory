# PjM7_UserStory
Групповой учебный проект по формализации требований и планированию разработки функциональности цифрового книжного сервиса на примере «ЛитРес».

В команде из трёх человек участвовала в проработке пользовательских сценариев, приоритизации функциональности, формировании бэклога и подготовке технической документации.

Моя основная зона ответственности разработка User Story Map: выделение ключевых пользовательских действий, декомпозиция функциональности на User Stories, определение приоритетов и формирование состава MVP и последующих релизов.

Совместно с командой сформировали бэклог в Asana с распределением задач, ответственными, сроками, приоритетами и статусами выполнения. Также подготовили проектную REST API-документацию с описанием эндпоинтов, HTTP-методов, входных и выходных данных, авторизации и обработки ошибок.

Результат: разработали комплект проектных артефактов для планирования реализации IT-продукта. Закрепила навыки управления требованиями, декомпозиции задач, приоритизации бэклога и взаимодействия между продуктовой и технической сторонами проекта.
